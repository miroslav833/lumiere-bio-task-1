# Where the image came from

image.png is Figure 4 of this paper:

Peled M, Nishi H, Weinstock A, Barrett TJ, Zhou F, Quezada A, Fisher EA (2017)
A wild-type mouse-based model for the regression of inflammation in atherosclerosis.
PLoS ONE 12(3): e0173975. https://doi.org/10.1371/journal.pone.0173975

The licence is Creative Commons Attribution 4.0 International, which the project accepts.

The file came off the publisher on 16 October 2026 at the size PLoS calls "large", and it is
3483 by 4171 pixels, PNG, with md5 e2122dd4bb844ff2d5d01379063fb290. It is the rendition the
publisher serves, so nothing in it was cropped, rescaled, sharpened, recoloured or annotated by
us. tools/decode_g004c.py only reads the pixels and writes nothing back, so the file on disk is
the file the publisher sent.
